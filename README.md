# ресурспак SPRMine

общий проект рангов и меню кланов. первый кандидат добавляет собственный темный фиолетово-белый фон со знаменем и иконки. это тестовая версия, не подтверждение отображения в клиенте.

исходный архив рангов v1.3 сохранен без изменений. сборка добавляет только ресурсы `sprmine`, не заменяет обычный шрифт minecraft и текстуры всех сундуков.

сборка: python 3 + Pillow, `python tools/build_pack.py`. результат в `dist`, SHA-1/SHA-256 в `dist/manifest.json`. `pack-source` содержит исходные ресурсы; размеры и модели задаются воспроизводимым генератором. старый ZIP остается доступным для отката.

совместимость первого кандидата: клиент Java 1.21.11; остальные версии не проверены. без принятого пакета SPRClans сохраняет обычное меню. пакет не дает игровых прав и не меняет данные игроков.

ручная проверка: главное меню с кланом/без клана, масштаб интерфейса, кликабельные слоты, значки рангов, отказ и ошибка загрузки. подтвержденные результаты записываются отдельно от успешной сборки.
